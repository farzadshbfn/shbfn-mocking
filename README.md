# Mocking

Test doubles for Swift protocols and structs, generated by the `@Mockable` macro.

```swift
@Mockable
protocol Greeter: Sendable {
    func greet(name: String) -> String
}

let mock = Greeter.Mock().with {
    $0.$greet.returns = "hi"
}

#expect(mock.greet(name: "x") == "hi")
#expect(mock.$greet.callCount == 1)
```

## Install

Add the package:

```swift
.package(url: "https://github.com/farzadshbfn/shbfn-mocking.git", branch: "main"),
```

Then, in **every target that uses the macro**, depend on `Mocking` and define `MOCKING` for debug builds:

```swift
.testTarget(
    name: "MyTests",
    dependencies: [
        .product(name: "Mocking", package: "shbfn-mocking"),
    ],
    swiftSettings: [.define("MOCKING", .when(configuration: .debug))]
),
```

The define is required. Everything the macro generates sits inside `#if MOCKING`, so without it the code compiles but `Type.Mock()` does not exist. Release builds ship no mock code.

## Usage

Mark the protocol or struct `@Mockable`. The macro generates three spellings:

| Spelling | Meaning |
|----------|---------|
| `Type.Mock()` | Controller — configure and verify through `$` peers |
| `controller.instance` | The value to inject (a protocol controller already conforms, so pass it directly) |
| `Type.mock` | Lenient ready instance, no configuration |

Configure with a single `.with { }` per controller, before you build the system under test. Then Given → When → Then:

```swift
let store = TokenStore.Mock().with {
    $0.$token.get.throws = AuthError.missingToken
    $0.$refresh.onCall = { _ in }
}
let sut = SUT(store: store.instance)

try await sut.ensureToken()

#expect(store.$refresh.callCount == 1)
```

Full reference — configuring, verification, structs and fixtures, generics, and standalone `Mock.Method` / `Mock.Property`: **[Documentation/Usage.md](Documentation/Usage.md)**.

Canonical examples live in the tests: `Tests/MockingTests.swift`.
